# 矿石工艺 · Ore Craft

> 每一条矿脉，都藏着尚未被发现的可能。

![矿脉深处的矿工与发光矿石](artwork/readme-banner.svg)

## 深处的回声

传说，最早的矿工曾在地底听见石头的低语。他们发现，矿石蕴藏的价值并不会随着开采而消失；只要懂得记录和转化，它就能以新的形态回到手中。于是，采矿不再只是寻找稀有之物，也成了探索万物之间联系的旅程。

**矿石工艺**是一款围绕采矿、资源转化与地下探索展开的 Minecraft 模组。它希望让每一次深入洞穴、每一份带回地面的收获，都成为下一次创造的起点。

适用于 **Minecraft 1.20.1 · Forge 47.4.28 或更高的 47.x 版本 · Java 17**。

## 构建

构建沿用 Gradle 9.2.1，需要 JDK 21 运行 Gradle；模组由 Java 17 工具链编译，可在 Java 17 游戏环境中使用。
安装 JDK 21 和 JDK 17 后，在项目根目录运行 `./gradlew build`（Windows 使用 `./gradlew.bat build`）；缺少 Java 17 时也可由 Gradle 工具链自动下载。
产物位于 `build/libs/ore_craft-1.20.1-forge-1.0.6.jar`，可放入 Forge 1.20.1 实例的 `mods` 目录。
这是面向 1.20.1 的源码适配版，不提供 1.21.1 世界存档的降级转换；请在独立的 1.20.1 实例中使用。

### IDEA 开发启动

IDEA 的 Gradle JVM 使用 JDK 21，重新加载 Gradle 项目后，选择共享运行配置 `Forge Client` 启动或调试。
该配置执行 `runClient`，会先生成 `build/moddev` 下的启动参数文件，再使用项目指定的 Java 17 工具链启动游戏。
降级前保留的 `Client` Application 配置可能引用缺失的参数文件并沿用 Java 21；开发启动请使用 `Forge Client`。
如只需准备开发文件而不启动游戏，可执行 `./gradlew.bat neoForgeIdeSync`。

## 矿质转化桌

本次新增的容器版名为“矿质转化桌”，原有直接使用全局 ME 的版本名为“矿质转化桌+”。两种桌子共用物品学习目录，矿质转化桌只提供一个标有“交易”的矿质容器槽；矿质转化桌+保留 ME 输入、输出口。

矿质转化桌使用以下有序配方：

| 铜锭 | 煤炭 | 铜锭 |
| --- | --- | --- |
| 金锭 | 黑曜石 | 铁锭 |
| 铜锭 | 钻石 | 铜锭 |

矿质转化桌与一个末影矿质容器进行无序合成，即可升级为矿质转化桌+。

放入普通矿质容器后，回收物品所得的 ME 和提取物品消耗的 ME 都存取这个容器；放入末影矿质容器后，则直接存取当前使用者的全局 ME 账户。未放交易容器或容量不足时不会消耗回收物品。关闭界面时，交易槽中的容器保留在转化桌内，并随世界保存，下次打开可继续使用。拆除转化桌会掉落其交易容器。矿质转化桌+的输入、输出口仍负责普通容器与全局账户之间的充值和提现，其中的容器在关闭界面时返还玩家。

## 矿质学习宝典

普通右键打开学习界面，可通过 Shift 点击逐件学习。手持宝典 **Shift + 右键容器** 批量学习目标库存；**Shift + 右键空气** 批量学习自己的主背包与快捷栏共 36 格物品。两种批量操作都不打开菜单，使用后显示新增、已学习及达到上限而跳过的物品种类数量。

学习仅登记物品默认类型，保留样本数量、附魔、耐久、容器 ME 和账户余额，不展开背包内物品的内部库存。重复类型只统计一次，无价格或被禁用的物品自动跳过。单件及批量学习共用 2048 种上限，记录与矿质转化桌、矿质转化器共享。原有容器的锁和访问权限校验继续生效。

## 矿质经验转化器

右键打开界面并放入矿质容器，将容器中的 ME 转为从方块顶面喷出的经验球。默认关闭，放置者使用 **Shift + 右键方块** 切换开关，手持物品时也可操作。

方块物品提示展示用途、每点经验的 ME 单价和开关操作，并以红色标注“经验产出消耗大量 ME，前期请谨慎使用！”。

UI 提供 **x1、x2、x4、x8、x16、x32、x64、x128** 八个生产档位，默认 x1。开启后每 20 游戏刻（正常刻速下一秒）生产一轮，每轮消耗 **10,240 ME × 倍率**，产出 **1 点经验 × 倍率**。余额不足所选档位或未放入容器时暂停且不扣费，不会自动降低倍率。切换档位、关闭、取出或更换容器会清除未完成的轮次。普通容器扣自身存储量，末影容器扣机器放置者的全局账户。关闭界面后机器继续工作，容器、开关和所选档位随世界保存；旧存档缺少档位时默认 x1。拆除方块会掉落容器，重新放置默认关闭且使用 x1。经验球使用原版拾取规则，附近玩家均可拾取。

| 档位 | 每轮消耗 ME | 每轮产出经验点 |
| --- | ---: | ---: |
| x1 | 10,240 | 1 |
| x2 | 20,480 | 2 |
| x4 | 40,960 | 4 |
| x8 | 81,920 | 8 |
| x16 | 163,840 | 16 |
| x32 | 327,680 | 32 |
| x64 | 655,360 | 64 |
| x128 | 1,310,720 | 128 |

经验单价为矿质附魔台一级普通常见附魔基础价（2,048 ME）的五倍，基础价调整时同比变化。1.20.1 版本保留每点经验 10,240 ME 的兑换费用，附魔价格按该版本附魔的稀有度和宝藏属性计算。其他模组改变附魔池、等级、权重或附魔能力时，需要重新评估此单价。

界面显示开关、供能余额、当前档位每轮消耗与经验产出及轮次进度。点击档位按钮进行选择，悬停可查看该档位的精确费用；绿色下沿标记当前选中档位。方块开启时侧面显示绿色晶石并发光，关闭时显示绿宝石矿石。

有序合成配方：

| 空 | 煤炭 | 空 |
| --- | --- | --- |
| 煤炭 | 绿宝石 | 煤炭 |
| 空 | 煤炭 | 空 |

## 管理命令

### 全物品回收开关

在聊天栏使用以下命令，需要开启作弊或具有等级 2 及以上的 OP 权限，也可由服务器控制台执行。

| 命令 | 作用 |
| --- | --- |
| `/orecraft convertall true` | 开启，允许所有已有 ME 价格的物品回收 |
| `/orecraft convertall false` | 关闭，恢复原有矿物来源和特殊状态限制 |
| `/orecraft convertall` | 查询当前开关值 |

新世界和未设置过此选项的旧存档均默认为 `false`。设置随世界保存，对所有维度、玩家、两种转化桌和矿质传输接口立即生效，重新登录和重载数据包后仍保留。

开启后，附魔、受损、改名和装有内容的物品均可按物品基础价回收；额外数据、容器内的物品和矿质容器中已存的 ME 不额外计价，回收时随原物品一起消耗。没有 ME 价格的物品仍不可回收。已有学习和提取规则保持原样，学习目录已满时仍可回收，但不新增学习记录。

### 清空学习记录

在聊天栏输入 `/orecraft clearlearned [目标]` 可清空玩家的全部矿质学习记录，需要开启作弊或具有等级 2 及以上的 OP 权限。此操作保留 ME 余额和所有物品，并立即刷新在线玩家的学习目录。

| 命令 | 清空范围 |
| --- | --- |
| `/orecraft clearlearned` | 自己 |
| `/orecraft clearlearned @a` | 所有在线玩家 |
| `/orecraft clearlearned 玩家名` | 指定在线玩家 |
| `/orecraft clearlearned UUID` | 指定 UUID 的在线玩家 |

服务器控制台也可以执行此命令，需要明确指定目标。清空后，转化桌、学习宝典和矿质转化器使用同一份重置后的学习记录。
